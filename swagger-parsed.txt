    ## Overview

    The MinistrySafe V3 API lets you manage users, trainings, and background checks for your organization.

    **Base URL:** `https://www.ministrysafe.com/api/v3`

    ## Authentication

    All requests must include a **Bearer** token in the `Authorization` header:

    ```
    Authorization: Bearer <your-api-key>
    ```

    Use an **API key** generated in the MinistrySafe dashboard.

    ## Pagination

    List endpoints return paginated results. Use these query parameters to control pagination:

    | Parameter   | Default | Description            |
    |-------------|---------|------------------------|
    | `page`      | 1       | Page number            |
    | `page_size` | 25      | Results per page (max 100) |

    Paginated responses include `page`, `page_size`, and `total_pages` fields alongside the `data` array.

    ## Filtering

    List endpoints support filtering via `filter[]` query parameters. For example:

    ```
    GET /api/v3/users?filter[name]=Smith&filter[user_type]=Volunteer
    ```

    ## Error Responses

    Errors are returned with an appropriate HTTP status code and a JSON body:

    - **Single error:** `{ "message": "Not found" }`
    - **Validation errors:** `{ "errors": ["First name can't be blank", "..."] }`
    - **Bulk operations:** A `207 Multi-Status` response with per-item `success`/`errors` details.

    ## Date Format

    All dates and timestamps are formatted as **ISO 8601** strings (e.g., `2025-06-15T14:30:00Z`).

    ## Webhooks

    Webhooks send HTTP POST requests to your configured URL when events occur in MinistrySafe.
    See the **Webhook Documentation** page in the Developer Center for full payload details, event types, and signature verification instructions.
